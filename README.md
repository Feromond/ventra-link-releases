# Ventra Link

Private voice, video and text chat for desktop. Your identity lives on your
devices: no phone number or registration needed.

**Download, see what's new and read how it works at
[ventra.dev/ventra-link](https://ventra.dev/ventra-link).**

Direct links to the newest version:

| Download | For |
| --- | --- |
| [macOS](https://ventra.dev/ventra-link/download/mac) (`.dmg`) | macOS 13 or later on Apple silicon |
| [Windows](https://ventra.dev/ventra-link/download/windows) (`Setup.exe`) | Windows 10 and 11 (64-bit) |
| [Linux AppImage](https://ventra.dev/ventra-link/download/linux) | Other Linux distributions (preview) |
| [Debian / Ubuntu](https://ventra.dev/ventra-link/download/deb) (`.deb`) | Debian, Ubuntu and similar (preview, no automatic updates) |

Every version, with its notes and SHA-256 checksums, is on the
[Releases](https://github.com/Feromond/ventra-link-releases/releases) page.

Installed apps check here for new versions and only install updates that
carry a valid signature.

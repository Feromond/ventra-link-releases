# Ventra Link

Private voice, video and text chat for desktop.

Download the latest version from [Releases](https://github.com/Feromond/ventra-link-releases/releases/latest):

| File | For |
| --- | --- |
| `VentraLink-*-macOS.dmg` | macOS 11 or later on Apple silicon |
| `VentraLink-*-Windows-Setup.exe` | Windows 10 and 11 (64-bit) |
| `ventra-link_*_amd64.deb` | Debian, Ubuntu and similar |
| `VentraLink-*-Linux-x86_64.AppImage` | Other Linux distributions |

Installed apps check here for new versions and only install updates that
carry a valid signature.
